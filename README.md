# Arbaan Portfolio

A Vite, React, TypeScript, Tailwind CSS, and Motion portfolio for Arbaan Qureshi.

## Local Development

```bash
cd frontend
npm install
npm run dev
```

## Production Build

```bash
cd frontend
npm run build
```

## Vercel

This repo is ready for Vercel from the repository root. See `VERCEL_DEPLOYMENT.md` for the full publishing guide.
